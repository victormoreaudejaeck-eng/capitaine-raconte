# ⚓ Le Capitaine Raconte

Histoires vraies de naufrages, racontées en dessin animé, pour TikTok, YouTube Shorts et Instagram Reels.

- `stories/<histoire>/scenes.json` : le script (voix, sous-titres, compteurs)
- `anim.html` : les dessins et animations
- `build.py` : voix (ElevenLabs), musique, montage → `videos/<histoire>.mp4`
- `brand/` : photo de profil et bannière
- `LANCEMENT.md` : stratégie, horaires, hashtags, légendes

Fabriquer une vidéo : `python3 build.py titanic`
